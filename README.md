# Case Técnico — Predição de Canal Aduaneiro
Este repositório contém o notebook e scripts modulares para análise exploratória, preparação de dados e modelagem preditiva do canal aduaneiro.

## Estrutura
- `notebooks/case_tecnico.ipynb`: análise completa (EDA + visualizações + modelos + resultados)
- `src/`: funções reutilizáveis (split temporal, preprocessor, modelos e avaliação)
- `data/`: arquivo `sample_data.parquet`

## Requisitos
- Python 3.10+
